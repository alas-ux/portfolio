A Short but maybe an Inspiring Story to Somebody

I took up Computer Science without knowing anything about it. Zero background, honestly. All I knew was that it involved “code” and “programming,” but I had no real understanding of what those meant. So when I started this subject, ITEC-50, which focuses on web development or creating websites, I was completely clueless. At first, I didn’t even know how to code using HTML and CSS, especially CSS, with all its properties and values, which I didn’t understand at all. I had no idea how rectangular boxes appeared on a webpage, only to later realize it’s because of things like background colors, padding, and other CSS properties. Little by little, I started to enjoy learning, even if it was difficult to grasp the logic of the code. I’ll admit, I often look things up online when working on activities, especially now in the second semester where our university setup is mostly self-study. One of the things I tried using is the W3SCHOOLS. I use it to figure out how to build certain layouts, or which properties and values I should use. I used it even while making this portfolio website. But it’s not because I wanted to cheat. I use it so I can learn. I treat it as a tool to help me understand what I want to understand, especially when there’s no one else I can really ask for help. Despite that, I’m genuinely happy that I’m learning, even if it’s just little by little. I even learned how to embed a video, HAHAHA! That might be a small thing to others, but as they say, “Progress, not perfection.” So go ahead and browse my quizzes, activities, and exams above.
